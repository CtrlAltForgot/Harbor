# Roadmap

Harbor follows a four-step homelab roadmap:

1. **Real downloads:** connect the existing UI and companion to qBittorrent on Unraid.
2. **Safe organization:** classify real file trees and move/copy them with verification.
3. **Review and retention:** correct uncertain matches and apply predictable seeding rules.
4. **Daily-use comfort:** package the Nobara desktop app, serve the web admin UI, and finish backup/logging/Unraid setup.

Anything beyond those steps is optional and will be built only if it proves useful in actual home use. See [PROJECT_PLAN.md](PROJECT_PLAN.md) for the working checklist.
