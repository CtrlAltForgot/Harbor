# Product and visual direction

Harbor treats remote downloading as moving cargo safely into a home port. The anchor-in-a-rounded-berth mark, muted sea-glass green, deep blue-black surfaces, compact Manrope display type, and restrained concentric depth give it a calm identity without copying platform assets. Status color is semantic: sea-glass for healthy/active, amber for review, coral for failures or destructive choices.

The main view answers destination, progress, speed, classification, and attention state in one row. “Server mode” is stated before submission and local mode will use a visually distinct destination confirmation. Rounded geometry is consistent at 8/10/14/20-pixel tiers. Motion is limited to progress, connection, sheet transitions, and direct manipulation feedback; reduced-motion preferences will disable it.

The bottom-right build control is a development-mode affordance: it exposes elapsed session time and the active implementation checklist. It will be disabled in release builds or repurposed as a processing/activity center.
