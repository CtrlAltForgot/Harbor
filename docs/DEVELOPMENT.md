# Development

Requirements: Node 22+, npm 10+, Rust stable for the desktop wrapper, and Docker for container tests.

`npm install` installs workspaces. `npm run dev` launches the companion on 7331 and Vite on 5173. `npm run check` runs strict type checking, tests, and production builds. Data defaults to `./data`; use `HARBOR_DATA_DIR` for isolation. Set `HARBOR_ENGINE=mock` until the real adapter lands.

The simulator advances active transfers by 1.25% each second. A name such as `Example.Show.S02E05` classifies as television; an unrecognized name completes into Needs Review.
