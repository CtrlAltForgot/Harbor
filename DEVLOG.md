Traced the user's inline `Bad Request` after reannounce to the shared transport boundary, not qBittorrent or port forwarding. Closed an Unraid path-casing failure exposed by the first large personal-library run. Setup now case-resolves the final path component to exactly one existing directory, refuses missing media roots, and rejects already-ambiguous duplicates before creating folders or starting qBittorrent. Repair reruns also read prior paths, IDs, and ports from `.env`, preventing a custom download root from reverting while correcting the media mount.
